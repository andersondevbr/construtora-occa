# Construtora OCCA

Site institucional da Construtora OCCA — casas de alto padrão em Teresina (PI).

Desenvolvido por [AndersonDev](https://www.instagram.com/anderson.fsfs).

## Estrutura

- `index.html` — página principal
- `css/style.css` — estilos
- `js/main.js` — scripts e animações
- `img/` — imagens do site

## Como visualizar

Abra o arquivo `index.html` no navegador, ou publique a pasta com o GitHub Pages (Settings > Pages > Branch: main).
